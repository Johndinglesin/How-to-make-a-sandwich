# Sandwich Engineering Guide

A comprehensive, single-page web guide to building the perfect sandwich using structural engineering principles.

## 🥪 Features
- **Structural Anatomy:** Breakdown of the "Blueprint" for a non-soggy sandwich.
- **The Ribbon Method:** Learn how to fold protein for maximum flavor surface area.
- **Hydrophobic Seals:** Instructions on using fats to protect your bread's integrity.
- **ASCII Diagrams:** Visual representation of the layering system.
- **Failure Analysis:** Troubleshooting guides for common sandwich issues like "The Slide" and "The Sog."

## 🚀 Usage
Simply open `index.html` in any modern web browser. 

## 📂 File Structure
- `index.html`: The complete website (HTML, CSS, and Content) in a single file for easy portability.

## 🛠 Built With
- HTML5
- CSS3 (Custom properties and semantic layouts)
- ASCII Art for lightweight technical diagrams
